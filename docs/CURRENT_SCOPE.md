# 현재 클라이언트 범위

## 로컬 책임

클라이언트는 Windows PC에서 `python -m app`으로 실행됩니다. 로컬 FastAPI 서버가 React UI를 제공하고, 시스템 트레이에서 UI 열기·서버 로그 확인·종료를 제어합니다.

## 지원 영상 범위

입력으로 지원하는 대상은 길이가 **10분 이상 6시간 미만**인 일반 업로드 YouTube 영상과 라이브 종료 후 다시보기(VOD) 영상입니다. 현재 라이브 스트리밍 중인 영상은 지원하지 않습니다.

영상 관련 작업은 모두 로컬에서 처리합니다. `/bin`의 `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe`를 사용해 영상과 메타데이터를 수집하고, 자막과 분석 보조 데이터를 만들며, 선택 구간을 렌더링합니다.

## 서버 연동

클라이언트는 서버에 인증, LLM, 원격 STT, 작업 이력 동기화를 요청합니다. 서버 URL은 `.env`의 `AVE_SERVER_URL`로 설정합니다. LLM·Whisper의 비밀 값은 클라이언트에 두지 않습니다.

원본 영상, 렌더링 결과, 로컬 경로는 서버로 보내지 않습니다. 스크립트 중요도, 채팅 밀도, 댓글 타임스탬프, 히트맵, 음량, 추천·선택·수정 이력만 전송합니다.

원격 STT가 필요한 경우 추출한 임시 오디오만 서버 HTTP API로 업로드합니다. 로컬 Whisper와 FTP는 지원하지 않습니다.

## 개발 상태

정적 레거시 UI와 `/legacy` 경로는 사용하지 않습니다. `ui/`에서 `npm run build`를 실행하면 `static/ui/`가 갱신됩니다. 설치 프로그램 배포는 아직 진행하지 않으며, 개발 실행은 `python -m app`을 기준으로 유지합니다.

## 로컬 SQLite 저장소

`db/ave-client.sqlite3`는 작업 상태, 편집 계획, 전사본, 요약, 후보 점수, 선택 및 재렌더링 이력을 저장합니다. yt-dlp가 수집한 영상·자막·메타데이터·썸네일 캐시와 자막·렌더링 결과는 `media/` 파일로 유지합니다. 기본 경로는 `DB_ROOT` 환경 변수로 변경할 수 있습니다.

개발 단계에서는 테스트·개발 실행으로 생성된 `media/` 작업물과 `db/` SQLite DB를 보존하거나 이전 파일 구조와 호환하지 않습니다. 저장 구조가 바뀌면 기존 작업물을 삭제하고 새 작업으로 검증합니다.
